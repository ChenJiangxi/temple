# 柱面经文为什么只在下部

作者要求字影几乎覆盖整段柱高。本次核对的是建筑几何与入射光，不是文字贴图或界面缩放。

## 采用的原图与网页数据

- 主体CAD二层平面：四柱半径250毫米，距入口外框约1700毫米；二层标高2.5米，柱顶约5.4米。
- 前屋面从入口侧6米高下降到内侧5.433米；经文屏高2.4至6米。网页的墙柱相对位置与上述提取值未发现偏离。
- 实际心经图案上下留白后，最上字孔约5.818米，最下字孔约2.712米。
- 经文屏到柱子朝入口表面的水平间距约1.47米；柱身高2.9米。
- 原作照片 reference-7.jpg 可见经文分布于柱身的大部分高度，支持作者的覆盖意图，但照片不能单独确定真实太阳方向或拍摄时屋面遮挡条件。

## 几何结果

把一束光沿射入方向追到柱面，光的下降高度等于墙柱水平间距乘以该剖面内入射倾角的正切。字孔顶部在柱上的投影上界也因此下降。

| 条件 | 墙柱剖面中的入射倾角 | 字影高度上界 | 可覆盖柱高范围 |
| --- | --- | --- | --- |
| 旧默认：30°N、南向、2026-03-20 12:00 | 约59.8° | 约3.29米 | 从2.5米起约0.79米，即27% |
| 同地同日、西向、16:30 | 约21.4° | 约5.24米 | 从2.5米起约2.74米，即95% |
| 同地同日、西向、17:00 | 约14.7° | 达到5.4米柱顶 | 几何范围可覆盖整个柱高 |

以上百分比是字孔投光的**高度范围上限**，不是文字白色像素覆盖率，也不表示圆柱360度同时有字。字孔之间有空白，圆柱侧面的投影和遮挡也会不同。完整建筑下的实际画面另由网页太阳和阴影计算，见 evidence/revision9/。

南向在春分附近，只改上午/下午时刻仍不能明显提高这个高度上界：此时太阳变低的同时也更偏向侧面，垂直于经文墙的剖面倾角仍接近60度。

若保持现有几何，覆盖约95%柱高需要剖面入射倾角不大于约21度；覆盖到顶部约需16度或更低。若坚持旧60度入射，需把墙到柱面距离降至约0.24米，或将最上字孔提高到约7.94米，都会显著改变原布局或体量，不能把它当作原图的小修正。

## 结论与界限

目前首先确认的是：我任意采用的南向春分中午示例，不适合展示作者的近满柱意图。不能由这个错误示例推断作者的柱位错误。

原位置仍保留；新增整柱观察视角。`?scenario=column-low-sun` 仅为同一建筑的西向16:30入射对照，页面明确标为非原作定位；此对照的播放时段为15:00—17:30，600倍约15秒。它证明当前几何在另一种真实太阳条件下可以接近满柱，不证明原寺庙应朝西，也不能替代原作地点、真北与目标时段的校准。屋顶图案在玉佛上的春分完整度是另一项要求，不能用这次柱面结果替代。

数值来源：`scripts/analyze-column-light.ts`、`glyph-bounds.json`、`report.json`；太阳函数沿用项目的NOAA/Meeus计算。没有移动柱子或楼板，也没有人为把经文贴到柱上。

`architecture.ts` 集中保存以上尺寸。JSON 保存选定区域的原始线段与圆，便于继续对照；小数误差和局部斜线属于原 CAD 数据。

`candidate-2` 装饰 DWG 的心经共有 1495 条闭合 SPLINE/POLYLINE 轮廓。此次直接填充这些原始轮廓，按奇偶关系保留字内空白，排除重复 HATCH；没有换字体、重新排字或续写经文。`sutra-original.svg` 为提取出的矢量图，`sutra-extraction.json` 记录范围。

旧版将楼面放在 3.12 m、柱子放在 z=0.48 m、屋顶做成对称低坡，均与这些原图关系不符。旧字孔还是字体重写版。这些误差已经撤销，不能将由此造成的无字影归因于原设计本身。

仍未确认：地点、日期所指的真实设计情境、真北和部分材料。雨链的功能由其 CAD 构形与作者“瓶子接雨水”的说明共同解释；不属于雨量、水力或施工连接计算。白墙局部、玉佛细雕及材质仍有重建解释，不能称所有细部已经精确复刻。

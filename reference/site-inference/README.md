在北京这个推算地点：春分 12:05—12:46，屋顶图案完整落在佛身上。

## 1. 屋顶图案什么时候「完整落在佛身」

光线追踪：17 个开孔按 2 厘米采样，浮雕按 `jade-relief-v7.bin` 的实际起伏，另含两侧白墙内表面（±1.9 米）、后墙和地面。

- 最里面一排 4 个开孔在佛像正上方偏后，无论太阳在哪，光都只能落在佛头上方的墙面。另有 2 个开孔总被浮雕上沿（厚 18 厘米）切掉一截。
- 其余 11 个开孔，需同时满足两个条件才全部落在佛身（每孔至少 95% 的光），且没有光落到地面或侧墙：
  - 墙柱剖面内的入射倾角在 **37°—64.5°**；
  - 太阳水平方向偏离入口正前方不超过 **−9°~+6.5°**。
- 倾角低于 37°，图案整体上移到佛头以上的墙面；高于 64.5°，最前排落到佛前地面。

横向容差只有十几度，所以只有太阳几乎正对入口时，图案才完整。入口朝南时，这每天只在正午发生一次，此时入射倾角等于正午太阳高度，即 90° − 纬度 + 当天赤纬。

## 2. 由春分推纬度

春分赤纬为 0，正午入射倾角 = 90° − 纬度。

- 纬度在 25.5°—53°N 之间时，春分正午图案都完整。
- 「春分时最完整」按「图案完整的那段日子以春分为中点」理解：90° − 纬度 = (37° + 64.5°) / 2 = 50.75°，得出纬度 **39.25°N**。
  - 以北京为例：正午图案完整的日期是 2月14日—4月29日、8月13日—10月28日，春分、秋分基本位于两段的正中。
  - 冬季太阳太低，图案上移到佛头以上；夏季太阳太高，最前排落到地面。
- 另一种理解是「春分时图案从佛座一直铺到头顶、覆盖最满」，对应约 26.5°N。但那样从秋分到春分整个冬半年图案都完整，春分并不特殊，所以不采用。

## 3. 经文满柱

经文字孔最高 5.818 米、最低 2.712 米，墙到柱面约 1.47 米，柱身 2.5—5.4 米。字影覆盖 95% 柱高，需要墙柱剖面内的入射倾角 ≤ 约 21°。

- 朝南建筑在春分这天，入射倾角全天固定等于 90° − 纬度（这是春分太阳轨迹的几何性质）。所以字影高度一整天不变，只沿柱面横向移动，接近「转经轮」的感觉。北京推算地点覆盖柱子下部约 54%。
- 北京推算地点，11月下旬至1月下旬的上午 10 点到下午 2 点，字影覆盖柱高的 85%—95%。冬至这天 9:35—11:02、13:23—14:50 超过 90%，正午约 89%。

## 4. 两个意图的关系

满柱需要的倾角（≤21°）和佛身图案完整需要的倾角（37°—64.5°）不重叠。所以在任何地点，这两个效果都不会在同一时刻出现。在推算地点，它们分属春分正午与冬季白天。

如果作者要求春分当天也接近满柱（按 50.75° 入射计算），必须改几何。两种改法任选其一：

- 墙柱距离从 1.47 米减到约 0.46 米；
- 经文最高字孔从 5.82 米提高到约 7.05 米，这会高出 6 米的屋面。

两者都会明显改变原设计，所以没有在模型里改。

## 局限

- 纬度依赖对「最完整」的解读。
- 经度不影响几何，只影响钟表读数。
- 没有考虑周边建筑、树木和地形的遮挡。
- 图案判定标准是每个开孔至少 95% 的光落在佛身。
